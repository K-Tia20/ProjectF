# ProjectF

Unreal Engine 5.5와 C++로 개발한 **3인칭 좀비 웨이브 액션 게임**입니다.

플레이어는 권총, 라이플, 검, 수류탄을 활용해 좀비를 처치하고, 제한 시간 안에 웨이브를 클리어해야 합니다. 각 스테이지의 전투를 마치면 활성화된 포탈을 통해 다음 스테이지로 이동하며, 마지막 스테이지에서 보스를 처치하면 게임을 클리어합니다.

## 개발 환경

| 항목 | 사용 기술 |
| --- | --- |
| 게임 엔진 | Unreal Engine 5.5 |
| 개발 언어 | C++ / Blueprint |
| 개발 도구 | Visual Studio 2022 |
| 입력 시스템 | Enhanced Input |
| UI | UMG |
| 시각 효과 | Niagara |
| AI 및 이동 | AIController / Navigation System |
| 버전 관리 | Git / Git LFS |

## 주요 기능

### 플레이어

- 3인칭 카메라 기반 이동 및 시점 조작
- 점프와 이동 방향 기반 대시
- 체력 감소, 회복 및 사망 처리
- 피격 시 화면 효과와 사망 시 래그돌 적용
- 스테이지 이동 시 플레이어 체력 유지

### 전투

| 무기 | 특징 |
| --- | --- |
| 권총 | 단발 사격 |
| 라이플 | 버튼을 누르고 있는 동안 자동 연사 |
| 검 | 근접 범위 내 적 공격 |
| 수류탄 | 투척 후 일정 시간이 지나면 폭발하며 범위 피해 적용 |

- 무기 교체 및 무기별 잔여 탄약 관리
- 라인 트레이스를 활용한 총기 명중 판정
- 머리 본과 전용 히트박스를 활용한 헤드샷 판정
- 사격 애니메이션, 발사음, 반동 및 카메라 흔들림
- 수류탄 보유 수량과 사용 쿨타임 관리

### 몬스터

**일반 좀비**
- 감지 거리, 시야각, 장애물 여부를 고려한 플레이어 탐지
- 플레이어 추적 및 근접 공격
- 타겟을 놓치면 마지막으로 확인한 위치 탐색
- 설정에 따른 최초 스폰 위치 복귀

**자폭 좀비**
- 폭발을 통한 범위 피해
- 약점 피격 시 즉시 폭발
- 폭발에 의한 주변 몬스터 피해와 넉백
- 주변 보스의 방어도에 피해 적용

**보스**
- 방어도에 따른 받는 피해 감소
- 플레이어를 놓친 위치 주변 수색
- 포효를 통한 부하 몬스터 소환
- 플레이어의 이동 상황에 따라 부하에게 포위 또는 돌격 명령 전달

### 웨이브 및 스테이지

- 총 4개 스테이지, 스테이지별 3개 웨이브
- 데이터 테이블 기반 몬스터 종류와 스폰 수량 설정
- 포탈 태그를 활용한 몬스터 스폰 위치 지정
- 일반 몬스터와 보스의 스폰 포탈 구분
- 남은 몬스터 수와 제한 시간 관리
- 스테이지 클리어 시 다음 스테이지 이동 포탈 활성화
- 마지막 스테이지의 3번째 웨이브에서 보스 처치 시 게임 클리어

### 아이템

- 몬스터 처치 시 확률에 따라 아이템 드롭
- 회복 아이템, 탄약 아이템, 수류탄 보급 아이템
- 플레이어가 아이템에 닿으면 자동 획득
- 스테이지에 따른 드롭 아이템 구성 변경
- 아이템 획득 알림 표시

### UI

- 메인 메뉴, 게임 HUD, 게임 오버 및 클리어 화면
- 플레이어 체력, 탄약, 무기 이름, 수류탄 수량 표시
- 현재 웨이브, 남은 몬스터 수, 제한 시간 표시
- 대시 및 수류탄 쿨타임 표시
- 명중, 처치, 아이템 획득 알림
- 포탈 상호작용 안내

## 조작 방법

| 입력 | 동작 |
| --- | --- |
| `W` / `A` / `S` / `D` | 이동 |
| 마우스 이동 | 시점 조작 |
| `Space` | 점프 |
| `Left Shift` | 대시 |
| 마우스 왼쪽 버튼 | 사격 / 근접 공격 |
| `1` | 권총 선택 |
| `2` | 라이플 선택 |
| `3` | 검 선택 |
| `G` | 수류탄 투척 |
| `F` | 활성화된 포탈과 상호작용 |

## 게임 진행

1. 메인 메뉴에서 게임을 시작합니다.
2. 스테이지에 등장하는 몬스터를 처치합니다.
3. 일반 웨이브의 몬스터를 모두 처치하면 다음 웨이브가 시작됩니다.
4. 스테이지의 3개 웨이브를 완료하면 이동 포탈이 활성화됩니다.
5. 포탈 근처에서 `F`를 눌러 다음 스테이지로 이동합니다.
6. 4번째 스테이지의 마지막 웨이브에서 보스를 처치하면 게임을 클리어합니다.

플레이어의 체력이 소진되거나 제한 시간이 끝나면 게임 오버가 됩니다.

## 실행 방법

### 1. 준비 사항

- Unreal Engine 5.5
- Visual Studio 2022
- Visual Studio의 **C++를 사용한 게임 개발** 워크로드
- Git 및 Git LFS

### 2. 프로젝트 다운로드

```bash
git lfs install
git clone https://github.com/K-Tia20/ProjectF.git
cd ProjectF
git lfs pull
```

이 저장소는 Unreal Engine 에셋과 일부 미디어 파일을 Git LFS로 관리합니다. 프로젝트를 열기 전에 LFS 파일을 내려받아야 합니다.

### 3. 프로젝트 빌드

1. `ProjectF.uproject`를 우클릭합니다.
2. **Generate Visual Studio project files**를 실행합니다.
3. 생성된 `ProjectF.sln`을 Visual Studio에서 엽니다.
4. 빌드 구성을 **Development Editor**, 플랫폼을 **Win64**로 설정합니다.
5. `ProjectF` 프로젝트를 빌드합니다.
6. `ProjectF.uproject`를 Unreal Editor로 엽니다.

### 4. 플레이

기본 시작 맵은 `Content/Level/Maps/L_MainMenu`입니다.

Unreal Editor에서 **Play**를 눌러 메인 메뉴와 게임을 실행할 수 있습니다.

## 핵심 클래스

| 클래스 | 역할 |
| --- | --- |
| `APFPlayerCharacter` | 플레이어 이동, 입력, 체력 및 사망 처리 |
| `UPFCombatComponent` | 무기 교체, 사격, 근접 공격, 수류탄 관리 |
| `UPFDashComponent` | 대시 실행, 효과 및 쿨타임 관리 |
| `APFGameMode` | 게임 규칙, 웨이브 진행, 클리어 및 게임 오버 처리 |
| `APFGameState` | 현재 스테이지, 웨이브, 남은 몬스터 수와 시간 관리 |
| `UPFGameInstance` | 스테이지 이동 시 플레이어 체력 보존 |
| `APFWaveManager` | 데이터 테이블에서 웨이브 정보를 조회 |
| `APFSpawnManager` | 포탈 태그에 따라 몬스터 스폰 위치 결정 |
| `APFPortalActor` | 몬스터 생성 |
| `APFLevelPortal` | 스테이지 이동을 위한 포탈 상호작용 |
| `APFPlayerController` | HUD 갱신, 메뉴 및 결과 화면 표시 |
| `APFMonsterCharacter` | 몬스터 공통 전투 및 사망 처리 |
| `APFBasicZombie` | 일반 좀비 탐지, 추적 및 공격 |
| `APFSuicideZombie` | 자폭 공격과 약점 판정 |
| `APFBossCharacter` | 보스 방어도, 수색 및 소환 패턴 |
| `APFBaseItem` | 아이템 공통 충돌 및 획득 처리 |

## 설계 특징

- **컴포넌트 기반 기능 분리**  
  전투와 대시를 별도 컴포넌트로 구성해 캐릭터의 역할을 나누었습니다.

- **데이터 테이블 기반 웨이브 구성**  
  스테이지와 웨이브별 몬스터 종류, 수량, 보스 여부, 포탈 태그를 데이터로 관리합니다.

- **C++와 Blueprint 연동**  
  핵심 게임 로직은 C++로 구현하고, Blueprint에서 에셋과 UI, 애니메이션을 연결합니다.

- **공통 클래스와 상속 활용**  
  몬스터와 아이템의 공통 동작을 기반 클래스에 두고, 각 유형의 기능을 파생 클래스에서 구현합니다.
